# 📊 HR Analytics Dashboard

This project presents a **Power BI dashboard** that provides insights into employee attendance and HR performance metrics for the organization.  
The goal is to help HR teams make data-driven decisions to improve employee engagement, reduce absenteeism, and optimize workforce planning.

---

## 🧾 Overview

The **HR Analytics Dashboard** analyzes attendance data from **2022–2023** and visualizes key metrics such as:
- Employee attendance trends  
- Department-wise presence and absenteeism  
- Overtime and leave patterns  
- Gender and role distribution  
- Average working hours and performance indicators  

---

## 🧠 Objectives

1. Identify departments with high absenteeism.  
2. Monitor monthly and yearly attendance patterns.  
3. Support HR managers in workforce planning and policy-making.  
4. Provide a quick visual summary of employee behavior and productivity.

---

## 🧰 Tools & Technologies

- **Power BI Desktop** — Data visualization and dashboard creation  
- **Microsoft Excel** — Data source (attendance records)  
- **Data Cleaning & Modeling** — Power Query

## 🧩 Data Preparation Steps

1. **Imported** Excel file `Attendance-Sheet-2022-2023.xlsx` into Power BI.  
2. **Cleaned** data using Power Query (removed duplicates, fixed missing values).  
3. **Created measures** in DAX for metrics like total attendance, absence %, and overtime.  
4. **Designed visuals** — bar charts, KPI cards, slicers, and trend lines.  
5. **Built filters** for department, month, and employment type.

---

## 📈 Dashboard Highlights

- ✅ Overall Attendance Rate  
- 🧍 Employee-wise and Department-wise Attendance  
- 🗓️ Monthly Trends (2022–2023)  
- 🕐 Average Working Hours & Overtime  
- 📉 Absenteeism Patterns by Department  

---

## 💡 Key Insights

- The **Sales** and **Operations** departments have the highest absence rates.  
- **December** shows a dip in attendance due to holiday season trends.  

---

## 🚀 How to Use

1. Download both files (`.pbix` and `.xlsx`) from this repository.  
2. Open `HR-Analytics.pbix` in **Power BI Desktop**.  
3. Update the data source path if necessary (to link the Excel file).  
4. Refresh the dashboard to load the latest data.
